# Evaporacion-pSi
Códigos creados en la práctica extracuricular de 2025 para el seguimiento de la saturación de líquido en muestras de silicio poroso, durante el proceso de evaporación. Hay 2 códigos, uno para el análisis de reflectancia de espectro completo, y el otro para el análisis de reflectancia de un láser.
